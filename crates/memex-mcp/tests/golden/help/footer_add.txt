Add a topic to a daily note's footer

Usage: memex footer add --vault <VAULT> --daily-note-id <DAILY_NOTE_ID> --topic-note-id <TOPIC_NOTE_ID>

Options:
      --vault <VAULT>                  Vault directory
      --daily-note-id <DAILY_NOTE_ID>  Daily note id (ULID)
      --topic-note-id <TOPIC_NOTE_ID>  Topic note id (ULID)
  -h, --help                           Print help

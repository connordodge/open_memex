Read the Vault Guide or return to an earlier text

Usage: memex guide <COMMAND>

Commands:
  get        Print the guide, creating it on the first call
  revisions  List the guide's kept earlier texts, newest first
  restore    Return the guide to an earlier text, keeping the replaced one
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

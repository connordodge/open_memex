Written comments and Corrections

Usage: memex feedback <COMMAND>

Commands:
  add   Add a comment on an Activity entry
  edit  Replace the text of an Open comment
  rm    Delete an Open comment
  ls    List one note's rows, or the rows with no note, newest first
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

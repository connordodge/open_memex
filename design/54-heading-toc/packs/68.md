## Where the design differs from or adds to the WI (the design wins)
1. **Depth-0 rows are bold.** Top-level entries (depth 0, drawn on the H1) are `fg0` w700; every other row is `fg1` w400. The WI only says "mono 12". The reference artifact keys this on **depth 0**, not on `h1` (an H2-only note's first heading is depth 0), so use depth.
2. **Current row is w500.** The Sketch text style is named `w500/accent` but the file embeds only JetBrains Mono Regular/Bold, so the PNG shows 400. Use `FontWeight.w500` (the reference artifact does; `OmType.eyebrow` is already w500).
3. **Hover fill is `surface3`** `#181D23` (WI says only "a fill"). Tooltip is `surface4` `#20262E`.
4. **Placeholder states (a, b) keep the header with the `⌘⇧O` keycap and no `· N` count.** `PanelPlaceholderTab` today builds `PanelHeader(eyebrow:)` only: the WI must give it a `trailing` slot (or the tab builds its own header). No subtitle is drawn (pass `subtitle: ''`).
5. **Rows at 1.5 are 35 px, not 39:** line height scales (27), the 4 px vertical padding does not.
6. **No board draws hover + focus + current on one row.** The combined look is derived below (section "Combined").
7. Flagged, not a mismatch: the `⌘` and `⇧` glyphs fall back to Menlo in the Sketch (JetBrains Mono lacks them); Flutter will use system fallback as `OmKbd('⌘K')` already does.

## List (`Entries`), starts y 89, 339 wide
- Column, **padding top 6, bottom 12**, no row gap: 16 rows = 6 + 416 + 12 = 434. Scrolls inside the panel when longer (the artifact keeps the header fixed above the list; the Sketch does not draw scrolling).
- **Row**: full width, height **26** at 1.0 / **35** at 1.5, padding L16 R16 (T/B 4), children centred vertically. Whole row is one tap target. Contents left to right: tag column, then guides, then text.
- **Tag**: `h1`..`h6`, mono 10 (x scale), lh 18 (x scale = 27 at 1.5, height 1.8), `fg2`. **Tag column width = round(22 x scale)**: 22 / 33.
- **Text**: mono **12** (x scale; same size at every level), lh 18 / 27 (height 1.5), single line, `TextOverflow.ellipsis`. Starts at x = 16 + tagW + **14 x depth**; available width = 339 − 32 − tagW − 14 x depth (e.g. 285 at depth 0, 243 at depth 3, 1.0). Colour/weight: depth 0 `fg0` w700; others `fg1` w400.
- **Indent guides**: one per depth step k = 0..depth−1: 1 px wide, **full row height**, `line2` (`#FFFCF019`), at x = 16 + tagW + **14 k + 4**. Step 14 does **not** scale. Rows stack with no gap, so guides read as continuous lines. Depth 0 has none.

### Combined (derived; no board draws it)
Layers, bottom to top: hover fill `surface3` → guides and current bar → current text/tag colours → focus ring. Hover + current: fill plus accent text, accentSoft tag and bar. Focus + current: ring plus the same three current marks, no fill. All three: all of it. The ring is at the row edge and the bar sits in the guide column (>= 42 px from the left edge), so they never touch; hover is a fill, the others are accent strokes/text, so the three stay distinguishable. Contrast below covers every combination.

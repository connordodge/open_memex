## Alignment (B3-C, pack #203 widths 301.00 / 160.53 / 140.47)
Delimiter cell `:--` or `---` (or bare) = left, `:-:` = centre, `--:` = right (R5). Header and body cells of a column share it. Inside the cell content rect (cell minus c = 8.1 each side): left text starts at x + 8.1; right text ends at cell right - 8.1 (B1 `1.5`: 835.05..859.35 in a cell ending 867.46); centre text midpoint = cell midpoint (B1 `done` 887.53..919.93, mid 903.73 = cell mid 903.735). Each wrapped line aligns on its own. Right/centre columns do not wrap (pack #203).

## Uneven rows (B3-D, W 291: 140.48 / 80.28 / 70.24)

## D19 probe zones (colour guarantees)
- Header band: `surface3` everywhere with no text ink in the **left/right padding strips** (x within 8.1 of any cell edge) at any y, and in the **bottom 4 px** (y 26.95 to 30.95) at any x. The WI's "bottom 8 px strip" (y 22.95 to 30.95) overlaps the header text's own line box (text line = band top + 4 .. + 26.95), so a probe inside it away from a padding strip can hit descender ink. Probe inside padding strips or the bottom 4 px.
- Rule rows: y = rowBottom - 1, x inside a padding strip (pills sit at line top + 2 .. + 19, never on this row).
- No `line2` at any vertical cell boundary.
- No `OmColors.selection` (`#7CFFB238`) anywhere (R16).

## WI vs design (design wins)
1. "Header band's bottom 8 px strip is `surface3`": true only away from header glyphs; see D19 probe zones.
2. The Sketch text layers for a wrapped second line carry a leading no-break space (B2 / B3-G `Text · override` shows `override` indented one column). That is a port artifact: a wrap space is dropped, so the second line starts at the content left.
3. Sketch frame heights (122.77, 168.67) are 22.94-pitch roundings; true heights are 122.75 / 168.65.
4. Header text colour is `fg0` in the editor but `fg1` in the card (board H).

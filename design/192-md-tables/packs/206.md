## Line geometry (R13)
- **Every line of the revealed table is one 22.95 line** (13.5 x 1.7), header, delimiter and body; wrapped raw lines stack at 22.95 each. T1.2: lines at y 200.38, 223.32, 246.26, 269.20, 292.14, 315.08 (22.94 pitch in the Sketch = 22.95). A 6-line table is 137.70 (board J).
- The delimiter line is a full line (22.95), not the 8 px it absorbs while rendered (pack #204: the +14.95 step).
- A raw line longer than W wraps like any prose line, at spaces, no hanging indent: continuation lines start at T (B3-G revealed: `... how markers hide per` / `line | reveal only the caret's line | 12 | yes |`).
- Whole-table reveal: a caret or selection on ANY table line reveals every line's markup (T1.2: caret in body row 1 also shows markers in rows 2, 3, 4).

## Pills in the revealed field
`layoutDecorations` adds one pill per inline-code span, from the field's line boxes (D15): rect = the content's glyph run +-3 px, top = line top + 2, height 17, radius 3, fill `surface4`; in T1.2 `buildTextSpan` is `| ` + backtick = 24.3 px in, so the pill is 94.31 .. 205.62 (111.31 = 13 x 8.1 + 6). The rendered (not revealed) table row's field contributes none (the grid paints its pills).

## Selection in a revealed table (B3-I)
Fill `OmColors.selection` `#7CFFB238` per pack #159: a text slice per selected line, the blank line above as one mono column (8.1 x 22.95), markers and pipes lifted to `fg1` `#D6D3CC` inside the selection (6.75:1 on `#28483B`). The caret 2 x 17 `accent`, cursor colour `accent`.

## Editing (R13)
Typing, the `[[` popover (anchored at the caret rect), the inline kind chip, save and undo/redo are the prose row's. Design draws no extra chrome for a revealed table.

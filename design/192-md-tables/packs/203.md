## The column-width rule (deterministic; reproduces every board table to within 0.03 px)
Per column i the grid measures, on the cell's built span (markup hidden), in px, **text only**: `n_i` = widest cell on ONE line, `m_i` = widest unbreakable word (split on spaces), and `noWrap_i` = the column is right- or centre-aligned (design: "numbers and short columns stay on one line"). Cell padding is **c on each side**, so with `N_i = n_i + 2c`, `M_i = m_i + 2c`, `B_i = min(3c, N_i)` (padding + ONE glyph, the break-anywhere floor):
1. **Spread (everything fits):** if `sum(N) <= W`: `w_i = N_i * W / sum(N)`. (Extra space goes to columns in proportion to their natural width; B1: 746/583.2 = 1.2792.)
2. **Floors:** `F_i = noWrap_i ? N_i : M_i`. If `sum(F) >= W`, drop the no-wrap rule and use `F_i = M_i` for all.
3. **Hopeless:** if `sum(F) >= W` still (so `sum(M) >= W`): if `sum(B) >= W`, `w_i = B_i * W / sum(B)`, else `g = (W - sum(B)) / (sum(M) - sum(B))` and `w_i = B_i + (M_i - B_i) * g`. Words now break between characters. Sums to W; no board reaches this branch.
4. **Shrink (the normal wide-table case):** find `f` in [0,1) with `sum_i max(F_i, B_i + (N_i - B_i) * f) = W`, by freezing: `free` = all; loop { `f = (W - sum(F_frozen) - sum(B_free)) / sum(N_i - B_i over free)`; any free i with `B_i + (N_i - B_i) f < F_i` is frozen at `F_i`; repeat until none }. `w_i = F_i` if frozen else `B_i + (N_i - B_i) f`. (Each pass freezes at least one column, so it terminates; `f` never goes negative because `sum(F) < W` and `F_i >= B_i`.)
Result always sums to W, and no column is below `F_i` (WI: min = widest word; the no-wrap floor is the design's addition). Equivalent to the browser's table layout the boards were rendered with.
Empty column (all cells empty): `n = m = 0`, `N = M = B = 2c`.

## Wrapping (T4 measures, T2 only takes line counts)
Text area of column i = `w_i - 2c` (floor 0). A cell wraps greedily at **spaces**; a word wider than the whole text area is first moved to a fresh line, then broken between characters (glyph boundary). In mono this is `capacity = floor((area + 0.01) / c)` columns per line; lay the cell out with `maxWidth = area + 0.01` so a line that exactly fits never wraps on float error. A wrap space is dropped (never drawn at the start of the next line). Line count `k_ij >= 1` (an empty cell is 1 line). Header cells wrap the same way. Right/centre columns are no-wrap, so they never wrap unless step 2 or 3 applied. Each wrapped line is aligned on its own (left / centre / right).

## Heights and positions (grid-local, origin = grid top-left, x from 0 to W)
- `k_h = max_j k_hj`; **header band height = k_h * L + H**: 30.95 for one line, 53.9 for two (22.95 x 2 + 8). H is the absorbed hidden delimiter line.
- **body row r height = max_j k_rj * L**: 22.95 / 45.9 / 68.85 for 1 / 2 / 3 lines. Row tops are cumulative from `bandHeight`; no gaps, no margins.
- **table height = band + sum(rows)**. Header-only table: band alone (30.95).
- **Rules:** one rule of thickness t = 1 under every body row except the last: rect `(0, rowBottom - t, W, t)`, i.e. the **last pixel INSIDE the row** (adds no height; it overlays the bottom of the row's last text line box). None under the header band, none under the last row, no vertical rules. Colour `line2` (`#FFFCF019`; `#282C2F` over `surface2`, `#2F3337` over `surface3`). In the Sketch each `Row rule` is per cell; joined they span 0..W with no gap.
- **Reveal delta** (revealed - rendered), single-line cells: `(2 + N) * L - (L + H + N * L) = L - H` = **14.95** for every N (N = 0, 1, 5 all 14.95; at scale 1.2: 27.54 - 9.6 = 17.94). With wrapped rows the revealed raw lines wrap by their own width, so the delta is no longer constant.

## Cell rects
Cell (r, j): x-range `[sum(w_<j), + w_j)`, y-range = its row's. **Content rect** = cell rect inset **c left and right**, and in the header band **H/2 (4) top and bottom** (text line at band top + 4); a body cell has **no vertical inset** (text line box starts at the row top). Cells of a row share top and bottom. Text x in the content rect: left `x + c`; right `x + w - c - lineWidth`; centre `x + (w - lineWidth)/2` (B1 `1.5` ends at cell right - 8.1; `done` centred in 72.55).

## Hit mapping (D13 support; a point is grid-local)
- Column: the x-range containing x; x < 0 clamps to column 0, x >= W to the last. Row: y < band is the header; else the body row whose y-range holds y (the rule pixel belongs to its row); y >= table height clamps to the last body row (the header if none).
- The point is **in the cell text** only if x is inside the content rect's x-range AND y is inside that cell's own laid-out text block (`k_rj * L` from the content top, header: from band top + H/2) AND not on the rule pixel. Then the caller maps by glyph (the cell's TextPainter; right of a line's end = that line's end).
- Otherwise the result is that cell with the **"cell text end" flag**: left/right padding, the rule pixel, the header band's top/bottom 4 px, below the cell's own text inside a taller row, an empty cell, and the clamped points. The caller puts the caret at the end of that cell's raw content (T1's trimmed cell range).
- Offsets (D13): an offset in the **delimiter line** maps to the header band (design silent on a caret rect: the caret never shows on a rendered grid, it reveals; use the first header cell's content rect, non-zero height); an offset in a **dropped cell** (cell index >= header count, R6) maps to the text end of that row's last drawn cell (index `headerCount - 1`).

## WI vs design (design wins)
1. WI #203 says min = widest unbreakable word, interpolated. The boards were laid out by a browser with break-anywhere minimums and no-wrap number columns; the rule above is the one that reproduces them (a plain word-min interpolation gives B2 table 2 column 1 = 142.77, board 153.58). Use this pack's rule.
2. WI "rules sit at the boundaries between body rows": the design draws the rule in the **last pixel inside** the upper row (y = rowBottom - 1), adding nothing.
3. WI "cells inset by the pack's padding": horizontal c = 8.1; header vertical 4 + 4; body vertical 0.
4. Sketch table frames read 122.77 / 168.67 / 99.81 (22.94-pitch rounding); true values are 122.75 / 168.65 / 99.8. Use 22.95 multiples.

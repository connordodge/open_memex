## WI vs design (design wins)
- **Dialog width.** A4 is 528 px (content 478); all six A5 states (and A6, A7, A9) are **472** (content 422). Pack uses **472**; A4 is the outlier. Lead to confirm.
- **Token hint.** A4 and A5·6 show a hint under the token field; A5 states 1, 2, 3 and 5 omit it (board compression), and state 4 replaces it with the error. The WI AC says the hint is shown. Recommend: show the hint always except when the token field has its own error.
- **Connecting.** WI says the primary is "disabled" and the fields disabled. The board draws "connecting…" at **full opacity** (spinner `loader2` 14 px `accentFg` + label, gap 7) and fields **not dimmed**. Draw it as the board does (block input and taps, no 40% dim). Cancel stays enabled.
- A5·1 draws the token **shown** (plain text, truncated with "…"; toggle active). A5 states 2-5 draw it masked.
- Error placement and copy match the WI (url error under server url; token error under token; L9 as a danger box above the buttons).

## Field (column, gap 6)
- Label: JetBrains Mono w400 11 / 16.5, `fg2`, lower case: "name (optional)", "server url", "access token".
- Input box: row, height 36, padding 0 / 10 (token: right 10 too, gap 8), fill `surface3` `#181D23`, border 1 inside `line2` `#FFFCF019`, radius 6.
- Text: name = Inter Tight w400 13 / 18.2 `fg0`; placeholder `fg2`, value = the URL's host ("nas.local"); url and token = JetBrains Mono w400 12 / 16.8 `fg0`. Masked token: bullets, mono 12, letter-spacing 2.
- Focused: border `accent.withAlpha(140)` (#7CFFB28C) plus a 3 px ring `accent.withAlpha(31)` (#7CFFB21F); caret 1 x 15 `accent`.
- Invalid: border `danger.withAlpha(166)` (#FF7A8AA6). Error row under the input: row gap 6, `alertTriangle` 12 px `danger` (2 px down), text JetBrains Mono w400 11 / 16.5 `danger`. Height grows by 22.5 (field 58.5 becomes 81).
- Hint (token): mono 11 / 16.5 `fg2`: "from <vault root>/.memex/access-token on the server. kept in your keychain." (edit: "saved in your keychain. paste a new one to replace it."). Wraps.
- Eye toggle (token): 24x24, radius 5, right-aligned inside the input; hidden = `eye` 14 `fg2`, no fill; shown = `eyeOff` 14 `fg0` on `surface4` fill. Key `connect-token-toggle`.
- Keys: `connect-name`, `connect-url`, `connect-token`.

## Actions row (right-aligned, gap 8, height 30)

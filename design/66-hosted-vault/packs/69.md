## WI vs design
- No number in the WI is contradicted. `StatusDot` states and colours match A12.
- GAP (not in the WI, needed by #97/#98/#99/#101): A12 draws **disabled = 40% opacity on the whole button** (primary and default). Today `OmButton` with `onPressed == null` only changes the cursor, it does not dim. Add `Opacity(0.4)` (or equivalent) in `OmButton` when `onPressed == null`, for every kind. Lead: assign to #69 or to each consumer.
- GAP: A12 draws **small buttons (24 px)** with 12 px label, horizontal padding 10, icon 12 px. `OmButton` today always uses 13 px text, padding 12, icon 14, whatever `size` is. #97 (retry, update token), #101 (retry now, update token) need this. Add: `size <= 24` means label 12 px, padding 10, icon 12 px (gap between icon and label stays 7).
- Danger hover is not drawn; use `hoverBg = dangerBg` (same as the agent kind keeps its bg).

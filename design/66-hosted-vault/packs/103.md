## WI vs design (design wins)
- Eyebrow, question, row content, buttons all match the WI. Board eyebrow "MEMEX · NAS" is `<VAULT> · <SERVER>` upper-cased (vault "memex", server "nas").
- The board draws **one** unsent-note row. For several notes (derived): rows stack with gap 6, each its own box; cap the list at 4 rows (about 160 px) and scroll inside the dialog beyond that.
- **Switch confirm (derived, reuses the layout):** question "unsaved changes couldn't reach <server>. switch anyway?", danger button "switch anyway". Everything else identical.
- The close and quit boards differ only in "close"/"quit" (question and danger button text).

## Dialog (all three; key `leave-confirm`)
Width 472, padding 24, column gap 16, fill `surface2` `#11151A`, border 1 inside `line2`, radius 10, shadow `0 24 64` black 60%. Height 204 with one note row.
1. **Eyebrow row**: row, gap 7, align centre: "<VAULT> · <SERVER>" (`OmType.eyebrow()`: JetBrains Mono w500 11, letter-spacing 1, `fg2`, upper case), then `StatusDot` unreachable (6 px hollow `warn` ring, [pack 69](69.md)).

3. **Note row** (key `leave-confirm-note-<n>`): row, gap 8, padding 8 vertical / 10 horizontal, align centre, fill `surface3` `#181D23`, border 1 inside `line2`, radius 6 (height 34.5). `LucideIcons.fileText` 12 px `fg2`; title Inter Tight w400 13 / 16 `fg1` `#D6D3CC` (grows, one line, ellipsis); right: "unsaved since 14:32" JetBrains Mono w400 11 / 16.5 `fg2` (24-hour `HH:MM` from the seam's since-time).
4. **Actions** (extra 4 px top margin, so 20 px after the last row): row, right-aligned, gap 8, height 30: ghost "cancel" (`leave-confirm-cancel`), danger button "close anyway" / "quit anyway" / "switch anyway" (`leave-confirm-proceed`; `OmButtonKind.danger`, [pack 69](69.md)).

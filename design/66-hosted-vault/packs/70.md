# Pack #70 · W0a — hosted first-load loading state and the two write snackbars

No board draws the loading state (lead ruling: "A12 'opening' spinner + centred fg2 'loading…'; no board"). This pack takes the spinner from **A12 states legend** (card "row icon states", row "opening · fg2, spinner") and the centred layout from **A11 workspace states** state 3 (id `C1417BC8-D388-4C99-B2D0-220061261770`). Snackbars: A11 state 4 and A12 ("banners (36px) and snackbar").
Board PNGs: [A12](../a12-states-legend.png), [A11](../a11-workspace-states.png). Crop: [row icons incl. opening spinner](70/a12-row-icons.png).

## WI vs design
- Loading state: **not drawn**. Values below marked (derived) are this pack's choice from A11·3's centred layout, so the implementer needs no further numbers. Lead may override.
- Snackbar copy: the WI lists two. The board draws only "couldn't reach nas. try again." ("couldn't reach <server>. try again."). "couldn't confirm with <server> — check before trying again" is **not drawn**; same snackbar style, text only. Both strings match the WI verbatim (lower-case, em dash).
- The board snackbar has **no action button**. Nothing in #70 needs one (action snackbars belong to #96 and are not drawn either; see pack 96).

## Hosted first-load loading state (in place of the list or body)
- Layout (derived from A11·3 body): `Center` → `Column(mainAxisSize: min)`, gap 10.
- Spinner: Lucide `loader2` (`LucideIcons.loader2`), 16 px, colour `fg2` `#9B9A94`. Spins continuously (rotation, about 1 s per turn; not drawn, assumption). Do not use `CircularProgressIndicator`.
- Text: "loading…" (U+2026, lower case), Inter Tight w400 13 px, line height 19.5 (heightRatio 1.5), colour `fg2`, centred.
- No background of its own: it sits on the parent surface (`surface1` for the body, `surface1`/panel for lists). Fills the area the list or body would occupy; centred both ways.
- A local vault never shows it on first load: it shows its normal empty state (no spinner). Reloads keep the previous value (no spinner).

- Retry button has a leading `LucideIcons.refreshCw` 12 px (WI does not say). Update token has no icon.
- "Opening" row has no × (see pack 92). Binary-missing local rows keep ×.
- Subline colour today `fg3` becomes `fg2` for local rows (matches hosted rows; `fg3` on `surface2` is only 3.46 : 1).
- Binary line to subtitle gap is 24 (today 28). Subtitle copy changes (WI has the new copy; `widget_test.dart` may assert the old one).
- Button labels today "create new vault…" / "open existing vault…" become "create local vault…" / "open local vault…"; keys `vault-picker-create`/`-open` stay.
- Not drawn (derived below): api mismatch / vault gone / schema refused rows' icon and server-row text for notMemex/apiMismatch; disabled buttons dim to 40% (needs the `OmButton` change in pack 69).
- WI "unreachable / token rejected ... warn / danger styling" matches A3·3.

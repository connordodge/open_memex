Board hues are illustrative; do not assert a hue in tests. Note the board colours "memex" (local, accent) and "memex · nas" (hosted, info) differently, so hash the full pill label, not only the vault name.

## Failed pill open: snackbar (current vault stays open)
Style = [pack 70](70.md) snackbar (surface4, radius 6, padding 10/14, Inter Tight 13 `fg0`). The board draws no action, so (derived): a `SnackBarAction` with label Inter Tight w500 13 px in `info` `#7AA2FF` (6.12 : 1 on surface4), lower case. Stable key `pill-open-failed-snackbar`.
| outcome | text | action |
|---|---|---|
| unreachable | "can't reach <server>" | "retry" |
| 401 | "<server> rejected the access token" | "update token" |
| vault gone | "<vault> is no longer on <server>" | "remove from recents" |
| api mismatch | "<server> runs memex <x>, which this app can't use. update the app or memex on the server so both are the same release." | none |
| schema refused | the server's error text | none |
Long text wraps; keep the snackbar one column, no truncation.

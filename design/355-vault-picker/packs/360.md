## What changes against the #351 dialog (everything else is unchanged)
The dialog is the existing one: 472 wide, `padding: 24`, `OmColors.surface2`, 1px `OmColors.line2` border, radius 10, shadow y24 blur64 `OmColors.dialogShadow`, over a 60% black scrim on the workspace (scrim `#00000099` = `OmColors.dialogShadow` colour, covers the window below the 28px title bar; the dialog is centred in it). Existing column: eyebrow `DELETE VAULT` (`OmType.eyebrow()`), 16 gap, title `move <name> to the trash?` (`OmType.sans` 15 w600 `fg0`, lh 1.4), 16 gap, path line (sans 13.5 `fg1`, lh 1.55), then the buttons row (right aligned, gap 8, buttons h32, pad 0/12, radius 6; cancel text `fg1` 13 on no fill with a transparent 1px border; "move to trash" text `danger` 13 on `OmColors.dangerBg`, 1px border `danger` at alpha 0x45 (`dangerLine`, `OmColors.danger.withAlpha(69)`)).

### New: the open-vault line (key `delete-vault-open-line`)
- Shown only when the vault being deleted is the open one. Sits 12px under the path line, 20px above the buttons.
- Row, gap 8, top-aligned, 422 wide, 21 high: icon `LucideIcons.info` 14 in `OmColors.fg2` inside a 14x17 box with `padding top 3` (same as the error line's icon), then text sans 13.5 w400 `fg1`, lh 1.55 (20.93).
- Copy verbatim: `memex is open, so open memex will close it first.` (`<name> is open, so open memex will close it first.`)

### States (S3)
| state | extra row under the open line | buttons | dialog h |
|---|---|---|---|
| 1 idle | none | cancel + `move to trash`, both enabled. Focus starts on cancel | 243.8 |
| 2 busy | none | both at 40% opacity (disabled). "move to trash" shows `LucideIcons.loader2` (loader-circle) 14 in `danger`, gap 7, then `moving to trash…` (label stays for the whole sequence). Dialog cannot be dismissed | 243.8 (button grows to 145 wide) |
| 3 failed | 12 gap, then the existing error row: `LucideIcons.triangleAlert` 14 `danger` (top pad 3) + text sans 12.5 `danger` lh 1.5, 400 wide: `open memex isn't allowed to move /Users/connor/memex. nothing was deleted.` (this is `vaultDeleteMessage` for TrashPermission; the line is whatever failure's existing message is) | both enabled; "move to trash" tries again (closing the vault first again) | 293.3 |
| 4 backup running | 12 gap, error row as above: `a backup of memex is running. try again when it finishes. nothing was deleted.` | cancel enabled; **"move to trash" at 40% opacity (disabled)**; re-enables by itself when the backup ends | 293.3 |

State 3 also means the vault has reopened behind the dialog (the dialog stays on top). State 4 applies to any local vault with a backup running, open or not (the open line is still shown only for the open one). Cancel and Esc still work in states 1, 3, 4; "nothing closes" until "move to trash" is pressed.

Contrast (text on actual background): fg0 on surface2 16.24; fg1 on surface2 12.26; fg2 icon on surface2 6.50; danger on surface2 7.33; danger on dangerBg-over-surface2 (button text) 6.38; danger error text on surface2 7.33. State 2 and 4 text at 40% opacity is a disabled control (exempt, as in #351).

## Flow F2.3 to F2.5 (prototype, all transitions `none`)
- F2.2 pill menu, `delete vault…` -> **F2.3** idle over the workspace (scrim + dialog).
- F2.3 `cancel` -> F2.1 (window, memex open). F2.3 `move to trash` -> **F2.4** busy (same dialog, 40% buttons).
- F2.4 -> **F2.5**: the dialog closes and the full-screen picker shows with no vault open (A3: no OPEN row, memex gone from RECENT and from the pills, so the pill count drops).
- Failure branch and backup-running branch are the S3 boards 3 and 4 (no prototype link).

## Where the WI differs from the design
- WI copy matches S3 exactly (`<name> is open, so open memex will close it first.`, `moving to trash…`, backup line). No numeric mismatch.
- The S3 stage background `#040607` behind the dialogs is board chrome, not UI; use the real scrim over the workspace (F2.3).
- Failed-state copy is the existing `vaultDeleteMessage` string for TrashPermission (`state/vault_delete.dart:36`); each failure kind keeps its own existing message.

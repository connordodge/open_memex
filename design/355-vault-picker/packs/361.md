## Type icon in the vault colour (A3, A4, A5)

## OPEN variant (A1, A4, A5, S4)
- Row border becomes 1px `accent` at alpha 0x4D (`OmColors.accent.withAlpha(77)`); fill stays `surface2`; the icon is in the vault colour.
- Tag `recent-row-open-tag-<i>`, 8 after the name: height 18, padding 0/6, fill `OmColors.successBg`, 1px border `accent` at alpha 0x45 (`withAlpha(69)`), radius 4; text `OPEN` mono 10 w500, letter-spacing 0.8, `accent`, lh 16.
- Hosted open row: name `team`, tag, then the usual `<status dot> nas · nas.local:7878` subline; no buttons, no menu on right-click.
- A click on it only closes the modal (#362). Hover fill rule is the same as other rows.

## Row states (S4, column 1 and 2)
- default `surface2`; hover `surface3`, border unchanged.
- **Keyboard focus on the row**: 1px `OmColors.accentSoft` ring just outside the row (a 58x58-high frame around the 56 row, radius 7.5), no layout shift. (The board label says 1.5px; the stroke is 1px, same as `PickerRowIconButton`.)
- **Keyboard focus on an icon button**: 1px `accentSoft` ring around the 24 button, drawn 1px outside it (26x26, radius 6.5), and its tooltip shows.
- Binary missing (S4 column 3): the red card replaces the binary line; THIS MAC and BACKUP buttons are 40% opacity; the first server action (`open vault on a server…`) takes the primary style (`accent` fill, `accentFg` text). Card: fill `dangerBg`, 1px `danger` alpha 0x45, radius 8, padding 16, title sans 14 w600 `fg0` `memex binary not found`, mono 11.5 `fg1` install lines, sans 12 `fg2` `local vaults need it. hosted vaults don't.`, button `locate memex binary…` (`surface3`, `line2`, h32).

## Row menu (S2 minus divider and `manage…`)
Right-click or keyboard on a row opens a menu at the pointer: fill `surface3`, 1px `line3`, radius 6, padding 4 vertical, width 200, shadow y12 blur32 `#0000008C`. Items 198x32, padding 0/12, gap 10, icon 14, label sans 13 w400. Hovered item fill `surface4`. Label `fg0`, icons `fg2`; `delete vault…` label and icon `danger`.
| row | items in order (icon) |
|---|---|
| local | `show in Finder` (`LucideIcons.folderSearch`), `remove from recents` (`LucideIcons.x`), `delete vault…` (`LucideIcons.trash2`) |
| hosted | `remove from recents` |
| open local | `show in Finder`, `delete vault…` |
| open hosted | no menu |
Item keys `vault-menu-finder`, `vault-menu-remove`, `vault-menu-delete`. Keyboard hover state of items is not drawn on the boards; reuse the hover fill.

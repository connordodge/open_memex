## Board vs WI
- Count case: board draws `· 9 blocks` (no text-transform); Spec req 1 and WI say uppercase -> build `· 9 BLOCKS` (lead ruling; Spec wins).
- Row height: board `min-height: 28`, not binding. Actual content-driven height 31.0 for a one-line preview (24 px button column with `padding-top: 1` = 25, plus 3 + 3).
  Spec/WI say "minimum height 30 (3 + 24 + 3)". Pin the board's 31.0 for a one-line row at 1x, and 30 as the floor (`greaterThanOrEqualTo(30)` holds either way).
- Topic row height: board links with a `.go` arrow measure 34 (a web inline-SVG baseline strut); the Not filed header measures 32.19. Spec says Not filed has the
  same geometry as a link row: use 7 + 18.2 + 7 = 32.2 for both. Do not pin 34.
- The board's `.fs-head` is `nowrap` on `Main`/`States` and `wrap` on `Scale`: wrap is required at 1.5x and 280 px.
- The board draws no hover arrow tooltip, no cursor; Spec requires the click cursor.

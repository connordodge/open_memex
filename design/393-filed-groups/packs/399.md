## Board vs WI
- Subtitle and day line: the board still draws both in fg3 `#6B6C68` (3.66:1); Spec req 18 and the WI change them to fg2 (6.86:1). Build fg2; Spec wins (existing contrast failure).
- Remove copy: board `only the excerpt goes.`; Spec req 16 / WI: `only this block is taken out of <Topic title>.` Spec wins (lead ruling).
- Preview cut: the WI rule is 48 grapheme clusters, trailing whitespace trimmed, then `…`. The board's Move example is exactly 48 characters (`Dash cancels into wall-slide should cost stamina`), so it agrees.
  The Remove example (`Check the jump arc against the double-jump height…`) is 49 characters, so it is cut at a word boundary instead; apply the same 48 rule to Remove (the Spec does
  not state one) and expect `Check the jump arc against the double-jump heigh…` for that string. Tests use the rule, not the board's string.
- The board redraws the dialog fields (static label above an underline input, 14 px spacer); the app keeps the WI #260 Material `TextField` with `labelText`. Only the new line, the
  Remove title and the colours above are binding.
- `Scale` draws no dialog: there is no 1.5x dialog board.

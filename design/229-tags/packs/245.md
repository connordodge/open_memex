## Style (all the new ink there is)
| state | colour | decoration | where drawn |
|---|---|---|---|
| tag at rest | `fg2` #9B9A94 | none | B4 "Tag in a list line", "Tag mid-sentence" |
| caret inside the tag (collapsed caret, **end edge included**: `#work\|` counts) | `accentSoft` #4FCF8A | none | B4 "Cursor on a tag" (`#wo\|rk`), F3.3, F3.5, B4 `#pr\|` / `#p\|` cells |
| Cmd held over the tag (A6 #247 wires the hover; A1 only provides the ink) | `accentSoft` | solid underline in the text colour | B4 "Cmd held over a tag", "Tag inside a transcluded excerpt" |
Nothing else changes: same size, weight and line as the surrounding text. No characters hidden, no background, no pill. Add the ink beside the existing ones in `LivePreviewInk` (`live_preview_styles.dart`): a `tag` ink gives `fg2`; the caret-inside case gives `accentSoft`. The existing `hover` flag already underlines.
- Colour precedence: a tag ink wins over the line's colour. In a heading the tag stays `fg2` while the heading words are `heading1`/`fg0` (B4 "Next to headings": H2 `Renewal call #work`, 19 px w700 bold: the tag is the same size and weight as its line, only grey).
- Dashed `fg3` underline stays the ghost wikilink's alone ("Tag vs ghost link: same fg2, told apart by the ghost's dashed underline"). The tag's Cmd underline is solid.
- A bare `#` with nothing after it is not a tag: it stays body colour `fg0` (B4 `call with Sam #`, F3.1). `#p` is a tag from the first letter (accentSoft with the caret at its end).
- Design is silent on a range selection across a tag. Suggestion: leave it `fg2`; only a collapsed caret turns it `accentSoft`.
- Line height is unchanged: body line 22.95 (13.5 x 1.7), headings take their own (`headingLineHeight`).

## The box (same as `[[`: `wikilink_autocomplete.dart` `:258-300`, share it, don't restyle it)
- 320 wide, `Material` `surface3`, 1 px `line3` border, radius 6, 4 px vertical list padding, max height 280. Key `tag-autocomplete`.
- Placement is the existing caret rule: 6 px below the caret line, flip above near the window bottom. The board draws every popover (including the `[[` reference) at the field's left edge; that is a mockup simplification, keep the app's caret anchoring.
- **Row:** 34 high (8 + 18 + 8), horizontal padding 12, gap 8. Selected row `surface4`; others transparent.
  - Tag row: `LucideIcons.hash` 12 px `fg2`; name in `OmType.sans` (Inter Tight) 13/18 `fg0`, ellipsis; **count** right-aligned, `OmType.mono` 11/18 `fg2`, same 12 px right padding. The name is the bare tag (`pricing`, no `#`).
  - Create row: `LucideIcons.plus` 12 px `accent`; label sans 13/18 `accent`, copy verbatim `Create new tag #<typed query>` (e.g. `Create new tag #prc`). Always last.
- Heights: 5 rows = 180 (5 x 34 + 8 + border); 1 tag + create = 78; create only = 44. Max 8 tag rows, then the create row.
- The existing `[[` row has no trailing count: add an optional trailing slot to the shared row widget, with `[[` output unchanged.

## Behaviour from flow F3
F3.1 `#` at line start: no popover. F3.2 `#p`: popover opens (Spec R25: after the first letter). Click or Enter/Tab on `pricing`: F3.3 completed tag `#pricing`, caret at its end, tag `accentSoft` (caret-inside ink from #245). F3.4 mid-line `#`: opens at once with the full list; click `pricing`: F3.5 `call with Sam #pricing`, caret at the end, `accentSoft`. Accepting writes `#name ` (trailing space, WI). Flow F3 shows typing only; a rendered tag's click is #247's.

## WI vs design (design wins) and gaps
1. **Order of the bare-`#` list.** WI, Spec R25 and the caption say "most-used tags first", but the board (B4 and F3.4) lists `health 2, memex 12, pricing 3, reading 5, work 7`, alphabetical. Implement count descending (ties alphabetical) as the text says; treat the board order as sample layout. Lead to confirm if Connor wants alphabetical.
2. **Create row with an empty query**: the board shows none; the WI is silent. Don't show one.
3. Accepting the create row: WI says it replaces `#query` with `#name `; the board caption says Enter "just leaves the text". Read as: same text result, no topic or note created. The board doesn't say whether that Enter also suppresses a newline; suggest it is consumed like any accept.
4. Sort order and top 8 for a typed query follow `fuzzyScore` (prefix, substring, in-order); the board has a single match per query, so it can't show ties.

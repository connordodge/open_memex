## Meta rail (`note_header.dart` `_MetaRail`)

`updated 2 hours ago` · `·` · `412 words` · `·` · the tags as a group `#memex #pricing #work`, gap **8** inside the group (14 between the rail's own items). Tags alphabetical, read-only, each clickable (`revealTag`), Key `rail-tag-<tag>`, no underline, no hover colour drawn. System tags never. The separate tag line (`if (note.tags.isNotEmpty)` Wrap, `accentSoft`, under the review chip) goes. With no tags the group and its leading `·` are absent (B3 "Only system tags": `updated just now · 31 words`).
- **WI vs design:** the board draws the **whole rail `fg2`**: text, both `·` separators, and **no clock icon**. The app today uses `fg3` for the text, `fg4` for `·` and a `LucideIcons.clock` 11 px `fg3`. `fg3` on `surface2` is **3.46:1, below 4.5**. Design wins: use `fg2` for the rail text and separators; the clock glyph isn't drawn (drop it, or keep it `fg2` if the lead wants to limit the change). The WI only asks for `fg2` tags; the rest of the rail is lead's call.

## × and its states (B3 grid, F2)
| state | draws |
|---|---|
| rest (F2.1) | names only: no ×, no box |
| hover or keyboard focus (F2.2, B3 "Hover on a tag") | name turns `accentSoft` with a solid underline; `LucideIcons.x` 12 px `fg2` appears 4 px after the name. `Remove tag <name>` semantics; Key `footer-tag-remove-<tag>` is the padded hit box (suggest the 16 px slot x the 18 px row; design shows only the 12 px glyph). Focus ring: not drawn |
| remove in progress | name drops to `fg2`, the × is replaced by a spinning `LucideIcons.loader2` 12 px `fg2`; the tag stays |
| failed | tag stays; an `InlineError` above the rows inside the footer: `Couldn't remove #pricing. The vault server didn't answer.` Dismissible |
| already gone (F2.3 / "Already removed") | × still succeeds, **no error**; the tag leaves the footer and the rail; Topics row stays, its rule stays; the Tags row (and its label) vanishes if it was the last |
| person writes the same tag (B3 last cell) | typed `#pricing` in the body: it leaves the footer; rail unchanged (`58 words · #memex #pricing #work`; that cell omits `updated`, a layout shortcut) |
- **Space reserved:** caption "Space is reserved, so nothing shifts." Item width = name + 4 + 12 (slot) at all times, then the 14 gap. The board's at-rest rows are drawn **without** the slot (`#memex` to `#pricing` is 14 apart, hover shows 30), which contradicts its own caption. Follow the caption: reserve the slot so hover changes no position (WI: "No scroll jump"). Report: board geometry contradicts the caption.
- `InlineError` (existing, `inline_error.dart`): `dangerBg` fill, radius 4, padding 4/4/4/12, mono 11 `danger`, 8 below it, dismiss a 22 px ghost button with `LucideIcons.x` 12. The board draws the dismiss glyph `danger`; the shared widget's ghost button is `fg1`. Keep the shared widget (Topics uses it); lead may overrule.
- The board gives copy only for the unreachable-server failure. For other failures use the thrown error's message as Smart Folder writes do (`MemexException.message`).
- × never appears on system tags (they're not shown).

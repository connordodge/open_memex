Revert after exactly 2 s. Announce `copied` once per copy (Spec req 31).

## Placement in a code block

Pinned to the block's top right: top 6, right 6 (absolute, does not scroll with the code). The code block reserves right padding for it:
Main uses 84 px, States uses 92 px (block padding is `10 R 10 12`). Use 92 so `Copied` (check + label, about 75 px wide) never
overlaps text at rest; the code scrolls sideways underneath the pinned button (Spec req 30).

## Variants on the board (the WI's API needs them)

| Where | Label | Icon | Size |
|---|---|---|---|
| Code blocks, Main Connect and Recall turn-on (hosted panel 5) | `Copy` | Main: copy icon. States panels 1, 4, 5: text only | 24 high, as above |
| States panel 4, Recall off, local | `Copy config` | text only | same |
| Token / address rows (States 1, 2, `.sm`) | `Copy` | none | same 24 / 8 / 6, same colours; `Hide` and `Reveal` (eye icon) are siblings of the same style, gap 6 |

The board is inconsistent about the leading icon (Main yes, States no). Recommendation: icon plus label everywhere except the token row,
matching Main, which the WI cites. The **API needs an optional `label` (default `Copy`)** for `Copy config`; the WI body's signature lists
`text`, `semanticLabel`, `sensitive` only. Copied state in the token row (`.sm.ok`) is the same colours.

## Semantics, keyboard, states not on the board

- Semantics: a button labelled `semanticLabel` (`Copy Claude Desktop config`, `Copy MCP address`, `Copy access token`, `Copy config file path`,
  `Copy Claude Code command`); the visible label `Copy` is not the Semantics label. After a copy the announcement is `copied`.
- Hover: board draws none. Recommend `OmColors.surface4` fill (same as `OmButtonKind.secondary` hover). Focus ring: not designed; follow #393.
- Busy guard, `KeyRepeatEvent`: see the WI; nothing visual.

## Conflicts: board vs Spec (Spec wins)

- Hosted Claude Code block on the board: multi-line with ` \` continuations, double quotes, unquoted entry name and URL, token shown as `9c1f6e0b…7c7f3a` even though revealed.
  Spec req 25 and 28: single-quoted values, `'memex-<vault name>'`, and the real full token when revealed. Layout (one line or backslash-continued) is CM's builder output; lead to confirm.
- Snippet token mask on the board is `••••7f3a` (4 dots); Spec req 26: 28 dots plus the last 4. Token row on the board already has 28.
- Board shows one note under the Claude Code block; Spec req 25 adds a second after it: `Pasting this into a terminal keeps the token in your shell history.` (same style).
- Board note text: `+00:00 is this Mac’s offset now. Claude Code sends it as written, so add the server again after a daylight-saving change.` (matches Spec with `<±HH:MM>` filled).
- Spec req 31 sensitive Copy is on every token-bearing block and the token row Copy; board does not distinguish.

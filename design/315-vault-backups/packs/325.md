## Sheet shell (same pattern as `widgets/hosted/setup_sheet.dart`; copy its dialog code)

- `showGeneralDialog`, barrier `OmColors.surface0.withAlpha(184)`, 150 ms fade, `Align(topCenter)`. The panel carries Key
  `backups-sheet`: `DecoratedBox` `surface2`, border `line2` 1, radius **bottom only** 10, shadow `dialogShadow` (0, 24, blur 64).
- Width 620 (`min(620, windowWidth - 32)`; under 652 px it narrows to the window less 16 px a side, B4-1).
  Padding L24 T21 R24 B22 (content width 570). Height is content-driven: no fixed header (24) or footer (30) boxes;
  use `ConstrainedBox(minHeight: 24 / 30)` and let text wrap. Scroll the body when taller than the window.
- Vertical rhythm: header, 14, hero card, 20, `SETTINGS` eyebrow (14 high), 8, settings group, then 14 to the footer
  row (or 20 to the button row in the picking states). Off state: hero, 14, lead paragraph. Hosted not-configured/too-old
  states: see below.
- Header row: eyebrow `BACKUPS · <VAULT NAME UPPERCASE>` (hosted: `BACKUPS · <VAULT> · <SERVER>` uppercase), mono 11 w500
  letterSpacing 1, `fg2` (= `OmType.eyebrow()`); right: close button 24x24 radius 5, `LucideIcons.x` 14 `fg2`, Key local
  `backups-close`, semantic label `close`. Escape and the barrier close the sheet.
- Section eyebrows `SETTINGS` / `ON <SERVER>`: same style as the header eyebrow.

## Status card ("hero"), Key `backups-status` on the text column only

Card: `surface3`, border `line2` 1 (error: `dangerLine`; warn: `warnLine`), radius 8, padding 16, row, gap 14, content-driven height.
Icon disc 36x36, radius 18, border 1, icon 16: normal = fill `surface2`, border `line2`, `fg1`; ok = `successBg` + border
`accent.withAlpha(77)` + `accent` check; running = `infoBg` + `info.withAlpha(77)` + `info` `loader-circle`; error = `dangerBg` + `dangerLine` +
`danger` `triangle-alert`; warn = `warnBg` + `warnLine` + `warn`. Text column (Expanded): title sans 17 w600, height 1.3, `fg0`; 4 below it
the body. Body styles: small = sans 12 height 1.5 `fg2`; paragraph = sans 13 height 1.55 `fg1`; file name = mono 12 height 1.25 `fg1`
(wraps by character); mono path = mono 11 `fg2`. 6 px before a last small line that follows a paragraph or file name.
Action button right of the text, top-aligned: `OmButton` primary, size 30, sans 13 w500. **Large text:** when title plus button do not fit
the card becomes a column and the button drops under the text with left inset 50 (36 disc + 14 gap), B4-2.

folder (not drawn) reads its full path. `<provider>` = display name without the account ("Google Drive", "iCloud Drive", "OneDrive"; a chosen folder: its folder name).
`<failedAt>` = "at 09:00" for today, "yesterday at 09:00" or "9 nov at 09:00" for earlier (the last two not drawn). `<server>` = the saved server's name, as
`hostedUnreachableMessage`. Each outcome gives a card **title**, a **detail** (the paragraph), and a **short** (the tail of the warning's semantic label).

## Mismatches (the design wins)

- WI says picking an option saves it. B2-2/-3 show a radio selection plus "cancel" / "turn on backups": selecting does nothing until "turn on backups" (then save destination, create `Open Memex Backups`, turn on). Saving at once happens only in the on-state dropdown (B2-9).
- WI says off "shows the toggle (`backups-toggle`)". The board draws a button "turn on backups…", and a ghost button "turn off backups" when on. One Key, `backups-toggle`, wraps whichever of the two is shown.
- B2-9 draws a compact success card without file name or req 26 line; B2-6 is the full card. Treat B2-9 as the menu example only; the card keeps the B2-6 content.
- B3-3 draws two rows in the read-only group (no `schedule`); B3-1/-2 draw three. Show three in every hosted state with the group.
- Keys the boards name that differ from the frozen set (`restore-choose-folder`, `restore-confirm`) are in pack 327; the frozen names win.
- Local-only Keys introduced here: `backups-close`, `backups-cancel`, `backups-turn-on`, `backups-destination-menu`, `backups-keep-dec`, `backups-keep-inc`, `backups-copy-command`, `backups-guide-link`, `backups-close-button`.
- Open (for the lead): where `docs/backups.md` points when pressed (the board draws only the link text); how `<i>` in `backups-destination-<provider>-<i>` counts (assumed: 0-based index in A2's list, choose-folder excluded).

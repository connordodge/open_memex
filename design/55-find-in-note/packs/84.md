## The design wins: mismatches with the WI body
- WI ink for the current match is surface0: matches the file (`#07090B`).
- WI says the lift is "the rule selection already uses". The code's selection lift (`livePreviewMarkerStyle(selected:)`) is
  fg2 to fg1. The file's B3.9 draws the selected run `hydration` in **fg0** `#F4F1EA` over the `#7CFFB238` selection fill;
  that is the existing selection look, not this WI's. Follow the WI for find ink (fg1) and report the B3.9 difference rather
  than changing the selection style.
- The file shows no un-matched, un-revealed marker colour other than fg2 (B3.4); fg3 markers appear nowhere in these boards.

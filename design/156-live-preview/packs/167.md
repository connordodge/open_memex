## Item row layout
- Row = marker column (width per #161: bullet 2, numbered digits+2, quote 2, task 4 / 6 revealed, in 8.1 px columns) + item text field filling the rest. Row x = T (level 1) or parent text x (child, R12). Row width = T + W − x.
- **Hanging indent (R10):** every wrapped line of the field starts at the item text x. A2: task row text x = T + 32.4 = 74.4, text width 617.61; bullet text x = T + 16.2 = 58.2, width 633.81; wrapped item = 2 x 22.94 = 45.88 high, 3 lines 68.81 (A2 task "Spike the marker parser in pure Dart: …" wraps to 3 lines).
- **First-line alignment:** the marker column is exactly the first line's height (22.95) and vertically centres its marker in it (circle top +4.47, dot centre +11.47); items align at the top, never centre on a wrapped item.
- **Heights:** 22.95 per line; the row is its wrapped line count x 22.95. **No gap between rows**, no row padding: consecutive rows touch (A1: H2 line 34 high ends exactly where the first task row starts).
- Quote row: marker column 2 cols (empty; band behind the whole row, pack #165), text right padding 8.1.
- Revealed task: column 6 cols, text moves right by 16.2 for that row only; children of a task do not move (R12).
- Nested example (A4-M "nested bullet"): level-1 bullet marker x = T, text at T + 16.2; child marker x = T + 16.2 (hollow dot unrevealed; `-` revealed, `fg2`), child text x = T + 32.4 (A4: 103.2 → 119.4 from T = 87.0).

## Segment, gutter, cards
- Daily note: text column T = field left + 14. The capture gutter (14 px) stays one column beside all rows: each capture rule spans from the top of its block's first line to the bottom of its last, across prose and item rows (A1: 74.38 for a 3-line block with H3 + task + prose).
- Topic note (A3): T = field left (no gutter); the excerpt card sits between two text segments, full column width (760), card margin 6 px vertical as built; the text segments are separate fields. Board gaps (A3): H2 "Evidence" line ends y 318.6, card 324.6 → 441.4 (6 above), next segment starts 459.4 (18 below, from the field's 18 px top margin).
- Text segment width = the page column (760 max, window − 56 minimum); caret 2 x 17 `accent`.

## Empty area, hint, launch
- **Hint** (single text segment, empty): `type [[ to link a note · write markdown…` as built: JetBrains Mono 13.5 `fg3` `#6B6C68` (3.46:1 on `surface2`; existing, below 4.5, hint text only). Shown only while the only text segment is empty; the design draws no hint.
- **Empty click area** below the last row, as built: segment min height = `minLines` x 22.95: **12 lines = 275.4 px** when it is the only text segment, **4 lines = 91.8 px** for the last of several, 1 line (no extra area) for other segments. A click there puts the caret at the segment end.
- Launch focus (WI): caret at the end of the first text segment; the design only shows the caret as 2 x 17 `accent` at the end of a line.

# Pack #159 · C0 seams — selection colour

Boards: **A4 States** (page "Option A", id `20C55F9E-126D-41C3-967B-A10C03BEE1F8`, 1440x3000), cells **H** (selection across two lines), **K** (selection across a paragraph, a heading and list items) and **N** (selected link and ghost text, added after review). Flow F1 draws no selection fill: it has the caret only.
PNGs: [A4-H](159/a4-h-selection.png) · [A4-K](159/a4-k-selection.png) · [A4-N](159/a4-n-selected-link-ghost.png) · [full A4](../a4-states.png).

## Decisions applied (coordinator + Connor, design wins over the WI)
1. **`OmColors.selection` is translucent: the Sketch's `sel`, accent `#7CFFB2` at alpha 56 = `#7CFFB238`.** This is the same value as the existing `selectionBg` (`accent.withAlpha(56)`, `colors.dart:51-52`); `selectionBg` stays for `topics_pane.dart:350`. Define `static final selection = const Color(0xFF7CFFB2).withAlpha(56);` (equal to `Color(0x387CFFB2)`); test: `OmColors.selection == const Color(0x387CFFB2)`. The WI's opaque `#29483B` is dropped.
2. Selected link text (`info`) and selected ghost text (`fg2`) switch to **`fg1`** while selected, like markers and done-task text (board A4-N). Underlines stay.

## Where the selection colour appears
- **Text slice** in a prose line or item text: a rect `selection`, height = the font's content box (17 px at 13.5; 21 px on the 34 px H2 line), top at line top + 2 (+6 on H2), spanning only the selected characters, revealed markers included.
- **Marker column** of a selected item line: the whole column (16.2 x 22.95 for a bullet) filled `selection`, marker text `fg1`.
- **Newline mark** at the end of a fully selected logical line, and a selected blank line: 1 mono column x full line height (pack #170).
- A4-H: item 1 "keep their offsets" + newline mark; item 2 marker column + "Block markers" (partial, no newline mark). A4-K: one range over a paragraph tail, a blank line, an H2 line and two items. A4-N: a link line (`[`, text, `](url)`, newline mark) and a ghost line.
- The fill is the same translucent value over every backdrop; its look over `surface2` (the field) is **`#28483B`**, over `surface3` (quote band, card) `#2E4F42`, over `surface1` (code box) `#244334`. It is a background only.

## Text colours inside a selection (contrast on the composite over `surface2`, `#28483B`; over `surface3` in brackets)
| text | colour | ratio |
|---|---|---|
| normal selected text | `fg0` `#F4F1EA` | 8.95 (8.05) |
| selected revealed marker, selected done-task text, **selected link text, selected ghost text** | `fg1` `#D6D3CC` | 6.75 (6.07) |
| wikilink alias | `accent` `#7CFFB2` (unchanged) | 8.08 (7.26) |
Unselected `fg2` markers are 6.50 on `surface2`; the lift to `fg1` inside the selection exists because `fg2` on the selection is only 3.58 and `info` only 4.06. Link underline stays 1 px (now `fg1`); ghost underline stays dashed `fg3` (A4-N).

## Caret (context for the field)
2 x 17 `accent` (`cursorColor: OmColors.accent` as built). No other selection UI.

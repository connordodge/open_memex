# Pack #159 · C0 seams — selection colour

Boards: **A4 States** (page "Option A", id `20C55F9E-126D-41C3-967B-A10C03BEE1F8`, 1440x3000), cells **H** (selection across two lines) and **K** (selection across a paragraph, a heading and list items). Flow F1 (caret) draws no selection fill: it has the caret only.
PNGs: [A4-H](159/a4-h-selection.png) · [A4-K](159/a4-k-selection.png) · [full A4](../a4-states.png).

## WI vs design (design wins)
1. **The design's selection colour is translucent, not opaque.** Sketch colour variable `sel` = `#7CFFB238` (accent, alpha 0x38 = 56/255 = 21.96%); the approved artifact CSS is `rgba(124,255,178,.22)`. The same fill is drawn over `surface2` (field), and the design never shows it over `surface3` / `surface1`.
2. **`#7CFFB238` is exactly the value `OmColors.selectionBg` already has** (`accent.withAlpha(56)`, `colors.dart:51-52`). `selectionBg` stays unchanged for `topics_pane.dart:350`; if the lead wants no duplicate, `selection` could simply alias it. The WI asks for an opaque token; the numbers below are for that.
3. The opaque composite over `surface2` is **`#29483B`** from the CSS 22.0% (`0xFF29483B`, WI value), or `#28483B` from the Sketch's 56/255 alpha (red channel rounds to 40 instead of 41). Use `0xFF29483B`; the 1-step difference is invisible.

## Token to add
`static const selection = Color(0xFF29483B);` beside `selectionBg` (`colors.dart`). Test: `OmColors.selection == const Color(0xFF29483B)`.
| backdrop | accent @ 56/255 over it |
|---|---|
| `surface2` `#11151A` (field, the design case) | `#28483B` / `#29483B` |
| `surface3` `#181D23` (quote band, excerpt card) | `#2E4F42` |
| `surface1` `#0B0E11` (code box) | `#244334` |
An opaque `selection` paints `#29483B` over every backdrop, so a selection inside a quote band or code box loses the band tint (design K shows no such case). A translucent token (`Color(0x387CFFB2)`) would match the Sketch on all backdrops; lead decides.

## Where the selection colour appears
- **Text slice** in a prose line or item text: a rect `sel`, height = the font's content box (17 px at 13.5; 21 px on an H2), top at line top + 2 (+6 on the 34 px H2 line), spanning only the selected characters, hidden markers included once revealed.
- **Marker column** of a selected item line: the whole column (16.2 x 22.95 for a bullet, full line height) filled `sel`, marker text lifted to `fg1`.
- **Newline mark**: 1 mono column wide x full line height at the end of a fully selected line (see pack #170).
- A4-H: item 1 "keep their offsets" + newline mark; item 2 marker column + "Block markers" (partial, no newline mark). A4-K: one range over paragraph tail, blank line, H2 line, two items.
- It is a background only: it never changes the text colour except the lifts below.

Boards (page "Option A"): **A1** daily note desktop (blocks at y 790–1070), **A2** narrow 720 (blocks at y 1210–1560), **A4 States** cells D (caret inside the code block) and L (block backgrounds stay in the text column). Page "Flows": **F1.3** (rich paragraph: pill under the caret line).

Terms: **T** = text column left edge (daily note: field left + 14, the capture gutter; topic note: field left). W = text column width (A1 746, A2 650, A4 cell 588). Real line height 22.95 (Sketch shows 22.94 and 2 px shorter text layers).

## WI vs design (design wins)
1. **Code text is inset inside the box**: 16.2 px (2 columns) from the left edge and 10 px from the right (CSS padding 15.2 / 9 + 1 px border); the WI paints only the box. A prose field cannot indent only fenced lines, and the box may not paint left of T. Open question for the lead; fallback: text at T, box from T.
2. **Vertical padding**: hidden fence lines are 8.0 each (7 px padding + 1 px border), pack #161. Revealed fence lines keep the same 8 px padding in the board (A4-D box 107.75 = 4 x 22.94 + 16): recommended: painter outsets 8 px top and bottom when revealed.
3. The pill, quote band and box radii below are exact; the quote band has **no radius and no border**.

## Quote band (A1, A2, A4-D, A4-M)
- `surface3` `#181D23`, x T, width W, height = the row's height (22.95 per line; a wrapped quote row 45.88 for 2 lines).
- Consecutive quote rows form one continuous band (no gap); the blank line or prose line after has none.
- Band includes the 2-column marker column (empty; `>` in `fg2` when revealed) and a 1-column (8.1) right padding after the text.
- Text italic `fg1` (pack #164, WI vs design 3).

## Horizontal rule (A1, A4-D, A2)
- One line, **1 px**, `line2` `#FFFCF019` (`OmColors.line2`; over `surface2` it reads `#282C2F`), x T … T + W, y = line top + 11 on a 22.95 rule line. The rule line itself is 22.95 high (blank-line height). Characters hidden off the caret line.

## Clipping to the text column (R6)
Nothing paints left of T. The 14 px capture gutter holds only the capture rule: x = gutter left + 6, width 2, `agent` `#B9A6FF` (agent capture) or `info` `#7AA2FF` (quick entry), height = the captured block's line boxes (A1: 74.38 for "From the agent" + task + flagged line). A4-L draws a dashed guide at T (annotation, not UI).

## Painting order
Backgrounds (box, band, pill) under text; selection above the backgrounds (an opaque `OmColors.selection` hides the band tint under a selection; pack #159 note); rule and box drawn from `LineBoxSource` rects only.

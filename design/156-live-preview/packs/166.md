# Pack #166 · B3 links — hover, Cmd-hover, ghost

Boards: page "Flows" **F2.1 plain hover on a link** (`4CB59093-D950-45FD-8D2A-4AE19C158743`), **F2.2 command held over a wikilink** (`12D0A04E-8261-4E21-9CB1-CDCE79664A95`), **F2.3 command held over a ghost link** (`5DF9FA62-FDC9-4273-AC0D-4D7B0DA71473`), each 700 wide; page "Option A" **A4 States** cell F.
PNGs: [F2.1](166/f2-1-plain-hover-on-a-link.png) · [F2.2](166/f2-2-command-held-over-a-wikilink.png) · [F2.3](166/f2-3-command-held-over-a-ghost-link.png) · [A4-F](166/a4-f-hover.png).
The mouse cursors drawn on the boards (I-beam, pointing hand) are macOS system cursors used as illustration, not app art: use `SystemMouseCursors.text` and `SystemMouseCursors.click`. No sprites.

## Board copy (the behaviour the design states)
A4-F: "Plain hover keeps the text cursor and a plain click places the caret. With ⌘ held over a link or resolved wikilink the pointer cursor shows and it underlines; ⌘-click opens it. A ghost ignores ⌘: no pointer, no underline change, and ⌘-click does nothing."

## States (text sample on every board: `Read the [Flutter TextSpan docs](…) and [[Byte offsets]].` / `Still to read: [[Obsidian live preview notes]].`, all lines unrevealed)
| case | cursor | style of the hovered token |
|---|---|---|
| F2.1 plain hover on the link | text (I-beam) | none: link stays `info` `#7AA2FF` + 1 px underline |
| F2.1 plain hover on a wikilink | text | none: `accent` `#7CFFB2`, no underline |
| F2.2 Cmd held over the resolved wikilink `Byte offsets` | **pointer (click)** | **underline added**: 1 px, colour = the text's `accent`, offset about 3 px below the baseline (Flutter's default decoration position is acceptable); text colour unchanged |
| Cmd held over a resolved link `[text](url)` (A4-F text) | pointer (click) | no visible change: it is already underlined (`info`) |
| F2.3 / A4-F Cmd held over the ghost `Obsidian live preview notes` | **text (I-beam), not pointer** | **none**: stays `fg2` `#9B9A94` with the dashed `fg3` `#6B6C68` underline (1 px, dash 3 / gap 2 on the board) |
- Hover region = the token's **visible** text only (`Byte offsets`, 98 px wide on the board, hidden `[[`/`]]` excluded; the link text without `[`, `](url)`).
- The wikilink hover underline appears only while Cmd is down and the pointer is over the token; releasing Cmd or leaving removes it (design shows the held state only).
- Flow F2: F2.1 → (click) F2.2 → (click) F2.3 → (click) F2.1 (prototype loop; there are no other transitions).
- Not drawn in the design (come from the WI only): Cmd+click navigation, flush-before-open, URL scheme allow-list, ghost threshold. Design says only: ghost Cmd+click does nothing (no note created) and keeps the text cursor.
- A line the caret is on (markers revealed) is not drawn with hover; design silent. Suggested: same hit rule on the visible token text.

## Sizes and positions (F2 boards, unrevealed line, body 13.5, line 22.95)
- Link text `Flutter TextSpan docs` 21 chars = 171 px; wikilink `Byte offsets` 12 chars = 98 px; ghost title 27 chars = 219 px (dashed underline 224 px wide in the board incl. rounding). Underline sits at line top + about 20.6 for the ghost.
- Hover creates no layout change: underline and cursor only.

## Highlights

This is the first public release of Open Memex: a macOS app for writing and organizing notes in a local vault, with the Bundled memex inside it and an MCP server for your AI agents (Claude Desktop, Claude Code, Raycast and other MCP clients). The README explains how to install it and connect an agent.

The download is a signed and notarized DMG on GitHub Releases. The same release has a standalone memex zip and a SHA256SUMS.txt file to check your download against. Open Memex is under the MIT licence. Its fonts are bundled, so the app never fetches fonts at runtime.

### What's new since v0.1.0

- **Backups.** Open Memex writes one `.memex.zip` file per vault into any folder you choose: iCloud Drive, Google Drive, OneDrive, a NAS share or an external disk. It backs up once a day and skips the day when nothing changed, and "Back up now" makes one straight away. `memex backup` and `memex restore` do the same from the command line, and a restore always makes a new vault folder. See `docs/backups.md`.
- **Delete a local vault.** A local vault's delete button on the vault picker, or "delete vault…" in its right-click menu, moves its folder to the Trash after you confirm. You can delete the vault that is open: Open Memex closes it first. Its backups are kept.
- **Vault management.** The "manage" button in the VAULTS header of the sidebar opens the vault picker over your open vault. Right-click a vault for show in Finder, remove from recents and delete vault. Vault pills and picker rows show a folder icon for a local vault and a server icon for a hosted one.
- **Keyboard buttons.** The picker and dialog buttons work from the keyboard.

## Upgrade

No vault changes. Vaults made by earlier builds at schema V6 open as they are.

## Requirements

Apple silicon Mac, macOS 14 or later.

## Highlights

Open Memex 0.7.0 makes very long notes fast and adds attachments. You can scroll a long transcript without stutter or the spinning beachball, and you can add files and images to any note.

### What's new since v0.6.0

- **Long notes are fast.** Scrolling very long notes, such as long transcripts, no longer stutters or shows the beachball. Only the row you are editing is a live text field. Outline, spelling and Find no longer do whole-note work on every change.
- **Attachments.** Add files and images by dragging from Finder, pasting (files or a screenshot), or ⋯ → Attach file…. Files are stored inside the vault (the objects/ folder), so they travel with backups. The limit is 100 MB per file.
- **Images and file cards.** Images show inline. Other files show as a card that opens in the default app. Scripts, executables and macOS location files (.webloc and similar) are revealed in Finder, never opened. Excerpt cards show attachment lines.
- **Search.** Text inside PDFs and attachment file names are searchable from ⌘K, as Passages and in a new Attachments group.
- **CLI and MCP.** `memex attach` adds an attachment from the command line. The MCP server has new `add_attachment` and `get_attachment` tools. Hosted vaults upload and download through the vault server.

### Known issues

- On a single very long paragraph (about 120,000 characters), typing has a little lag and each Find step takes a fraction of a second (#177).
- Select All on extremely long notes can stall for several seconds before recovering (#178).

## Upgrade

This release migrates vaults to schema V9 the first time it opens them. Back up first (the vault's Backups sheet → Back up now, or `memex backup`). After that, 0.6 can still open and read the vault but can't change it; update every Mac that uses the vault to 0.7.0.

V9 only adds tables for attachments; existing notes are unchanged.

Self-update offers 0.7.0 to 0.6.0 installs.

A 0.7.0 app connected to an older vault server can't attach files larger than 8 MiB (it shows a server-too-old message) until the server is updated. A 0.6.0 app keeps working against an updated server.

## Requirements

Apple silicon Mac, macOS 14 or later.

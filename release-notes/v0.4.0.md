## Highlights

Open Memex 0.4.0 lets your AI agents edit the notes you wrote, and keeps you in control of every edit. You can mark any note read-only for agents, see what each edit changed, and restore an earlier version in one click.

### What's new since v0.3.1

- **Agents can edit notes.** The new `edit_note` tool changes a note's text by exact find-and-replace, or rewrites the whole body when the agent passes the note's current version. It never touches the title, the frontmatter, the footer or any excerpt, and each edit says in one to three short lines what it did. There are now 38 memex tools.
- **Read-only for agents.** A note's ⋯ menu has "Read-only for agents". A flagged note shows a crossed-out bot icon by its title, and agents can't edit or tag it. Daily notes and the Vault Guide don't offer the toggle. `memex read-only set|clear` does the same from the command line.
- **Restore.** Every agent edit appears in the note's Activity tab with its bullets and a Restore button. Restoring keeps the current text as a version you can return to. `memex revisions list|restore` does the same from the command line.
- **Edits while the note is open.** An agent's edit appears in the open editor without a conflict when you have nothing unsaved. On a topic note, your edits and an agent's edits to different paragraphs are merged, and your caret stays where it was.
- **Hosted vaults.** A vault server running 0.4.0 supports all of this. Against an older server the toggle, the icon and Restore are hidden. Anyone with the server's token can still clear the read-only flag through the app's API; separate app and agent tokens are planned.

## Upgrade

This release migrates vaults to schema V8 the first time it opens them. Back up first (the vault's Backups sheet → Back up now, or memex backup); older versions can't open a migrated vault.

## Requirements

Apple silicon Mac, macOS 14 or later.

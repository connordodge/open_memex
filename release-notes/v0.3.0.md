## Highlights

Open Memex 0.3.0 makes your AI agents visible and brings older notes back to you. You can see which agents are connected to your vault and what they wrote, set up Claude Desktop and Claude Code from one sheet, get echoes of related passages from your past notes, and catch typos with macOS spelling and grammar in the editor.

### What's new since v0.2.0

- **Agents sheet.** Window ▸ Agents… (⇧⌘A), the sidebar footer's `OPEN ↗` or the status bar opens one sheet with four tabs. Live shows each connected agent and its recent writes. Connect gives copy-ready setup for Claude Desktop and Claude Code, including a hosted vault's token, which is masked until you reveal it and kept out of clipboard history. Tools lists every memex tool, grouped, with the ones that write marked. Semantic recall shows how much of the vault is embedded.
- **Live agent activity.** The bottom of the sidebar shows which agents are connected right now, whether they are working, and a short feed of what they wrote ("filed 1 block to Reading"). It works over stdio, on a hosted vault server and through `memex serve --remote`. The feed never shows your note text.
- **Echoes.** The right panel's new echoes tab shows passages from other notes that resemble the one you are reading, with how long ago you wrote them. Click one to open that note at the passage, or press link to add a link to it. It needs the embedding model (about 130 MB), which is downloaded only when you press Download. `memex echoes` does the same from the command line.
- **Spelling and grammar.** The editor underlines misspellings in red and grammar slips in blue, in live preview and in Source mode. Right-click for suggestions, Learn Spelling and Ignore. Edit ▸ Spelling and Grammar has Check Document Now (⌘;) and the usual toggles. Learned words are shared with macOS and listed in the vault settings.
- **Filed from this day.** On a daily note, the Activity tab's "Filed from this day" groups blocks under the topic they were filed to. Topic titles are links, and each block has Move to…, Remove and File in… fixes.
- **Better search chunks.** Notes are re-chunked by section, so footers and daily-note markers no longer match searches and a topic made of transcluded passages shows the passage text as its snippet.
- **Command line.** New `memex tools`, `memex embeddings status`, `memex echoes` and `memex words`.

Searches made while older notes are first being indexed can be slightly slower.

## Upgrade

This release migrates vaults to schema V7 the first time it opens them. Back up first (the vault's Backups sheet → Back up now, or memex backup); older versions can't open a migrated vault.

On the first open, notes are re-chunked and their embeddings are rebuilt in the background, so semantic search and echoes fill in over the next few minutes on a large vault.

## Requirements

Apple silicon Mac, macOS 14 or later.
